Squad builder

What does each player want?

  • ✨ Auto: get me the most marks.
  • 🛡️ Carry: I'll play something strong so the others win.
  • 🎯 Hunt: I want marks on one specific character.

Only characters a player has unlocked are suggested. Each squad gets a goal: the route (Chest, Dark Room, Mother, Beast or Greedier) where the players get the most marks they're still missing.

How the win chance works

Each character has five 0–5 stats:

    For a squad:

    • Kill speed = 0.6 × best Damage + 0.4 × average Damage
    • Staying alive = 0.5 × best Survival + 0.5 × average Survival. Dead players keep fighting as ghosts, so one survivor matters most.
    • Team help = total Team help, each character counted once, max 6. Only counts with 2+ players.
    • Team cost = total Team cost. Only counts with 2+ players.
    • Skill load = how far the average Skill is above 2.5
    • rating = 0.45 × Kill + 0.35 × Alive + 0.3 × Help − 0.2 × Cost − 0.25 × Skill load; win chance = 10% + 17% × rating (5–95%)
    • Goals: Auto counts your marks ×1, Carry ×0.2 (so you get a strong or helpful character), hunting a picked character ×1.5.
    • Route: a run takes one route, so marks are counted for the best route. Its own bosses count fully; bonus marks you can add on the same run (Boss Rush, Hush, Mega Satan, Delirium) count 0.6×.
    • Score = win chance × weighted marks on that route. The win chance is an estimate from the stats above, not real game data.

      How to use Co-op Marks

      Compare Binding of Isaac progress with your friends and pick what to play together.

      1. Add players. Paste a Steam profile link or Steam ID in the box at the top and press + Add player (up to 4). The profile and its game details must be public on Steam. Click a player's color circle to change their color.
      2. Share. The page address holds the player list, so just send the link to your friends.

      Everything comes from public Steam achievements, so some things (hard mode, a few tainted marks, save resets) are best guesses. Reopen this anytime with the ? button.
